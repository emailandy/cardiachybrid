## Task
S00 — calibration harness + eval metrics
Implement the sensor calibration harness and evaluation metric suite in `sensors/eval/`.
Creates:
- `sensors/eval/metrics.py`: evaluation metrics scoring sensor output against ground truth.
- `sensors/eval/calibrate.py`: calibration harness loading threshold configurations from `sensors/calibration/*.yaml`.
- `sensors/eval/report.py`: evaluation reporting utility.
- `sensors/eval/ground_truth/README.md`: specification and README for ground-truth test fixtures.

Sensors are DETERMINISTIC. Every threshold is CALIBRATED against ground truth, never chosen because it looked right. Thresholds live in `sensors/calibration/*.yaml`, keyed by bay or device model, never hardcoded.
