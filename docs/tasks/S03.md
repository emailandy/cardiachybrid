## Task
S03 — S1 + S6 motion and coverage
Implement Sensor S1 chest-ROI optical flow compression motion detection and Sensor S6 channel coverage visual occlusion detection in `sensors/s1_s6_motion.py`, ROI configuration in `sensors/calibration/roi_config.yaml`, and unit tests in `tests/test_s1_s6.py`.
Measures chest compression displacement via optical flow and flags visual occlusions or provider crowding over the ROI.

Sensors are DETERMINISTIC. Every threshold is CALIBRATED against ground truth, never chosen because it looked right. Thresholds live in `sensors/calibration/roi_config.yaml`, keyed by bay or device model, never hardcoded.

## What this gate does NOT prove
Determinism is not accuracy. A sensor that returns the same wrong answer every run passes this gate. The accuracy gate is deferred, not waived.

The floor did not cost recall; fragmentation did, and the floor exposed it.
