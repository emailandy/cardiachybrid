## Task
S08 — S4 monitor OCR
Implement Sensor S4 monitor OCR telemetry ingestion in `sensors/s4_monitor_ocr.py`, monitor display layout calibration in `sensors/calibration/monitor_layouts.yaml`, and unit tests in `tests/test_s4.py`.
Extracts numeric vital signs (HR, SBP, DBP, SpO2, ETCO2) from defibrillator/monitor display ROI. Abstains cleanly rather than guessing when numeric OCR confidence < 0.80.

Sensors are DETERMINISTIC. Every threshold is CALIBRATED against ground truth, never chosen because it looked right. Thresholds live in `sensors/calibration/monitor_layouts.yaml`, keyed by device model, never hardcoded.

## What this gate does NOT prove
Determinism is not accuracy. A sensor that returns the same wrong answer every run passes this gate. The accuracy gate is deferred, not waived.
