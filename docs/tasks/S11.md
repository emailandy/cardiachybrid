## Task
Implement `scripts/check_claims.sh` (backed by a deterministic Python verifier `scripts/claim_verifier.py`) to enforce mechanical verification of cited claims in documentation and scorecards:
1. **Commit SHA Verification**: Extract 7-40 char hex git hashes cited in `docs/` and verify that `git rev-parse --verify <hash>` exits 0.
2. **Ground Truth Quote Verification**: Extract citations of GT intervals (e.g. `GT #1 [147.0, 155.0]`) and verify exact equality against `fixtures/ground_truth_simvideo2.json`.
3. **Scorecard Metric Drift Verification**: Extract scorecard metrics in `docs/` (CCF, F1, Precision, Recall, MAE, FP counts) and verify bit-for-bit equality against live execution of `sensors.eval.report`.
4. **Pytest Count Verification**: Extract test suite pass count cited in `docs/STATE.md` and verify against `pytest --collect-only -q`.
5. **Metric Labelling Discipline**: Assert that every accuracy or CCF figure in `docs/SENSOR_FINDINGS.md` is accompanied by explicit window, tier, and tolerance labels (e.g. `±3.0s`, `70.75–922.0s`, `≥5.0s`).
6. **Internal Component Arithmetic**: Scan component sum assertions (e.g. `X gaps = Y seconds`, `A + B = C`) and assert mathematical equality.
